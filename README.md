# Núcleo de Operações e Planejamento Acadêmico (NOPA) - UNIFIO

Bem-vindo ao espaço de desenvolvimento e projetos do NOPA. Nosso objetivo é criar e manter soluções tecnológicas que impulsionam a inteligência institucional, otimizam as rotinas administrativas e apoiam o planejamento estratégico do Centro Universitário de Ourinhos (UNIFIO).

## 🚀 Frente de Atuação

* **Inteligência Institucional:** Análise de dados e desenvolvimento de modelos preditivos para acompanhamento acadêmico, projeções de faturamento e permanência de alunos.

## 🛠️ Stack e Tecnologias

* **Análise de Dados e Machine Learning:** Python, Streamlit, Pandas, Scikit-learn.
* **Desenvolvimento Web:** JavaScript, Node.js, React.
* **Bancos de Dados:** MySQL, PostgreSQL, MariaDB.
* **Infraestrutura e Deploy:** Frameworks (Streamlit) e integrações via API.
